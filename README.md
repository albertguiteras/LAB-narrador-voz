# Lab: Narrador de Voz con Web Speech API

## 📖 Descripción del Laboratorio

Aplicación que convierte texto a voz utilizando la API nativa `window.speechSynthesis`, permitiendo al usuario seleccionar idioma, velocidad, tono y reproducir contenidos.

---

## 🎯 Objetivos y Requisitos Técnicos

- [x] Integración con la Web Speech API (`SpeechSynthesisUtterance`)
- [x] Carga y filtrado de voces disponibles en el navegador
- [x] Controladores de reproducción (Play, Pause, Stop, Rate, Pitch)
- [x] Experiencia interactiva accesible

---

## 🛠️ Tecnologías y Herramientas

- **JavaScript ES6+**
- **Web Speech API**
- **HTML5 & CSS3**

---

## 🚀 Cómo Ejecutar el Proyecto

```bash
# 1. Clonar el repositorio
git clone https://github.com/albertguiteras/LAB-narrador-voz.git

# 2. Abrir index.html en tu navegador o mediante Live Server
```
